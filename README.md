## 2. Installing a theme
First of all, make sure you have installed Vencord / BetterDiscord

   * Step 1: Download the theme file, somewhere you can find it.
   * Step 2: Open the themes folder:
      * Go to your Discord's settings
      * Under themes, click on the "Open themes folder" button
   * Step 3: Put the theme file inside the themes folder
   * Step 4: Reload Discord using CTRL+R (or CMD+R on MacOS)
   * Step 5: Enable the theme:
      * Go to your Discord's settings
      * Under themes, enable your theme by clicking the switch
